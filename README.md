# Sleepet Wake-up Showcase

A standalone animated preview of Sleepet’s **medium-night wake-up** screen. Open `index.html` through a local web server or the GitHub Pages URL. The scenery and Mocha animation are embedded in the looping background video; the frosted summary card and sleep continuity graphic are rendered in HTML/CSS/SVG.

The scene plays silently at 0.75× speed. The two bottom controls are visual elements for the product demo and do not navigate. This repository is intentionally separate from the full Sleepet flow. Additional wake-up states can be added here later.

## Local preview

From this directory, run a static web server (for example, `python -m http.server 8766`) and open `http://127.0.0.1:8766/`.
